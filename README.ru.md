ControllerHelper — приложение для Windows 11, которое позволяет с геймпада переключаться между рабочим местом с мониторами и игрой на телевизоре. Оно работает в системном трее и открывает оверлей с основными действиями: перейти на ТВ, вернуться к мониторам, включить мониторы вместе с ТВ, продолжить игру и открыть Flydigi Space Station.

**Код самого ControllerHelper полностью сгенерирован искусственным интеллектом по запросам пользователя.** Это экспериментальный проект: успешная работа на одном компьютере не гарантирует совместимость с другим телевизором, видеокартой, драйвером или контроллером. Сторонние библиотеки и протокольные материалы имеют собственных авторов и лицензии.

## Скачать

[Последний релиз для Windows x64](https://github.com/eleaf33/controllerhelper/releases/latest) — скачайте архив `ControllerHelper-…-win-x64.zip`, распакуйте **целиком** и запустите корневой `ControllerHelper.exe`. Установка .NET отдельно не требуется. Журналы автоматически создаются в `logs` рядом с EXE. Файл `SHA256SUMS.txt` в релизе позволяет проверить целостность архива.

**Публичная сборка не содержит приватных ключей Hisense.** MQTT-сопряжение, выбор входа и выключение Hisense в ней недоступны; для них нужна собственная сборка с локальными материалами по инструкции ниже. Переключение дисплеев и звука, Wake-on-LAN и LG не требуют этих ключей.

Приложение поддерживает **английский и русский языки**. По умолчанию выбран английский, в том числе при обновлении старых настроек без выбора языка. Для смены откройте **PC → Language / Язык**, выберите **Русский**, нажмите **Save settings**, завершите приложение через трей и запустите снова. Переключатель языка описания выше не меняет язык приложения. Названия устройств и сообщения Windows или драйверов могут оставаться на языке системы.

## Возможности

- Сохранение конфигурации мониторов ПК и отдельного профиля телевизора.
- Переключение дисплеев, разрешения и частоты ТВ; настройка масштаба там, где это допускает Windows.
- Выбор аудиовыходов для ПК и ТВ. Можно сохранить временно недоступный HDMI-выход: после переключения изображения приложение ждёт его появления до 10 секунд, затем использует выбранный аудиовыход ПК, если звук ТВ недоступен.
- Автоматическое открытие Steam Big Picture при переходе на ТВ и закрытие Big Picture при возврате к ПК. В текущей версии Steam необходим для действия «Играть на ТВ».
- Сетевое пробуждение телевизора через Wake-on-LAN.
- Управление LG webOS: сопряжение, получение списка входов, выбор HDMI и выключение.
- Управление совместимыми Hisense VIDAA: сопряжение по PIN, выбор входа и выключение через локальный протокол RemoteNOW/VIDAA.
- Открытие установленного Flydigi Space Station в области оверлея и управление курсором с геймпада.
- Настраиваемое сочетание кнопок для оверлея и отдельное сочетание аварийного возврата на мониторы.
- Автоматическая запись диагностических журналов в папку `logs` рядом с корневым EXE.
- Английский и русский для настроек, оверлея, меню трея, диалогов сопряжения, статусов и ошибок приложения.

## Как это работает

1. Пользователь выбирает дисплеи и аудиоустройства для двух профилей: «ПК» и «ТВ».
2. Приложение получает события выбранного контроллера через Microsoft GameInput. По сочетанию кнопок открывается оверлей.
3. При выборе «Играть на ТВ» выполняются настроенное пробуждение и выбор входа телевизора, затем применяется конфигурация дисплеев Windows, выбирается звук и открывается Steam Big Picture.
4. При возврате сначала восстанавливаются мониторы и звук ПК. Для настроенного и сопряжённого телевизора может выполняться сетевое выключение.
5. Операции переключения выполняются последовательно. Отмена и ошибки учитываются при восстановлении предыдущего состояния; сбой HDMI-аудио не должен отменять успешно переключённое изображение.

Дисплеи определяются через Windows Display Configuration API (`QueryDisplayConfig`, `SetDisplayConfig`), а не по фиксированным номерам HDMI. Аудиоустройства перечисляются через Windows Core Audio. Для смены устройства по умолчанию применяется COM-интерфейс `IPolicyConfig`, который не является публично документированным стабильным контрактом Windows.

LG управляется через webOS SSAP по WebSocket, Hisense — через локальный MQTT/TLS. Это отдельные сетевые команды: наличие HDMI-кабеля само по себе не означает поддержку включения телевизора или переключения его входа с ПК. Совместимость сетевого управления зависит от модели и прошивки.

Flydigi запускается своим штатным EXE; ControllerHelper ждёт, пока клиент сам покажет главное окно, после чего размещает внешнее окно поверх оверлея. Исходники и бинарники Flydigi в этот репозиторий не входят.

## Требования

- Windows 11 x64, версия ОС не ниже `10.0.22000.0`.
- Контроллер, доступный через Microsoft GameInput, и установленный компонент GameInput.
- Телевизор, подключённый к видеовыходу ПК, для переключения изображения.
- Локальная сеть и разрешённое управление телевизором для сетевых функций. Wake-on-LAN должен поддерживаться и быть включён на самом ТВ; обычно требуется MAC-адрес его сетевого интерфейса.
- Установленный и зарегистрированный в Windows Steam для действия «Играть на ТВ»: текущая версия всегда открывает Big Picture при этом действии.
- Flydigi Space Station устанавливается отдельно, если нужна его карточка в оверлее.

Для запуска опубликованной самодостаточной сборки отдельно устанавливать .NET не требуется. Для сборки из исходников нужны Windows, PowerShell и **.NET SDK 10.0.401**, закреплённый в `global.json`. Для MQTT-управления Hisense дополнительно нужны локальные материалы совместимости, описанные ниже; приватные ключи в GitHub не публикуются.

## Первый запуск

В **[подробной инструкции](docs/SETUP.ru.md)** описаны конкретные кнопки, сохранение раскладок, HDMI-звук, сопряжение, режим двух экранов, обновление и диагностика. Краткий порядок:

1. Соберите проект по инструкции ниже либо распакуйте готовую публикацию целиком в доступную для записи папку.
2. Запустите корневой `ControllerHelper.exe`. Папки `lib` и `lang` должны оставаться рядом с ним.
3. На вкладке «ПК» выберите мониторы и звук, затем сохраните текущую рабочую конфигурацию.
4. На вкладке «ТВ» выберите телевизор, аудиовыход и необходимые видеопараметры.
5. Сначала проверьте локальное переключение с уже включённым ТВ. Затем при необходимости настройте блок LG или Hisense и выберите HDMI компьютера. MQTT-функции Hisense требуют локальной сборки с материалами совместимости.
6. Выберите геймпад и сочетание кнопок оверлея. По умолчанию используется удержание **A + View около 0,5 секунды**.
7. Сохраните настройки и проверьте переход на ТВ и возврат к мониторам.

В оверлее крестовина переключает действия, A подтверждает, B закрывает. Аварийный возврат по умолчанию выключен: его можно включить в настройках и назначить отдельное сочетание, например удержание LB + RB в течение двух секунд. Автоматического таймера возврата после смены изображения нет.

Обычного запуска без прав администратора достаточно. Для управления внешним окном Flydigi приложения должны иметь совместимый уровень доступа. При обновлении ControllerHelper сначала завершите старый экземпляр через трей: повторный запуск передаёт команду уже работающему приложению.

## Сборка и проверки

```powershell
git clone https://github.com/eleaf33/controllerhelper.git
cd controllerhelper
dotnet --version
.\verify.ps1
.\build.ps1
```

`verify.ps1` выполняет восстановление зависимостей по lock-файлам, аудит NuGet, Release-сборку, автоматические тесты и проверки публикации. `build.ps1` повторяет необходимые проверки и создаёт самодостаточную публикацию для `win-x64` в `publish-controllerhelper`.

Публикация в отдельную папку:

```powershell
.\build.ps1 -OutputDirectory .work\publish-local
```

Структура результата:

```text
publish-controllerhelper/
  ControllerHelper.exe   # загрузчик
  lib/                   # приложение, .NET и зависимости
  lang/                  # языковые ресурсы
  build-manifest.json    # состав публикации и SHA-256 файлов
  logs/                  # создаётся при запуске
```

Аргументы запуска: `--overlay` — открыть оверлей, `--to-tv` — перейти на ТВ, `--to-pc` — вернуться к ПК. Запуск без аргументов открывает настройки.

Проверка двуязычной версии: **352/352 тестов**, включая полноту перевода, соответствие параметров сообщений, сохранение языка и форматирование дат/чисел. Автотесты проверяют логику, локальные TLS/MQTT-сценарии и сборку; они не гарантируют работу конкретного оборудования. Последнее изменение открытия Flydigi требует отдельной визуальной проверки на целевом ПК.

Английские строки интерфейса проверены по словарю LibreOffice English (US) и вычитаны в контексте. Источники терминологии и правила перевода перечислены в [Localization/GLOSSARY.txt](Localization/GLOSSARY.txt).

### Локальные материалы для Hisense

Исходники собираются, а все тесты выполняются без приватных ключей телевизионного протокола. Но для реального MQTT-управления Hisense необходим клиентский сертификат с ключом соответствующего профиля. В исходниках оставлен только публичный сертификат `vidaa_client.pem`.

Если у вас есть законно полученные материалы совместимости, перед сборкой поместите в `ThirdParty/Hisense/`:

- `vidaa_client.key` — ключ к публичному `vidaa_client.pem` для старого профиля;
- `remotenow_client.pem` — сертификат и ключ профиля RemoteNOW;
- `vidaa_ios_client.pem` — сертификат и ключ профиля VIDAA V2.

Файлы исключены из Git через `.gitignore`; не добавляйте их принудительно. Затем выполните `build.ps1`. Без этих файлов MQTT-сопряжение, выбор входа и выключение Hisense сообщат об отсутствующих материалах. Локальное переключение дисплеев и звука, Wake-on-LAN и LG не требуют этих ключей.

Сборка с добавленными локальными ключами включает их в ресурсы приложения. Не публикуйте такие бинарники или архивы как способ обойти исключение ключей из репозитория. Источники протокольных материалов и относящиеся к ним уведомления перечислены в [NOTICE.txt](ThirdParty/Hisense/NOTICE.txt). Тестовые TLS-клиенты используют отдельные временные сертификаты, создаваемые при запуске тестов, и не могут заменить сертификаты настоящего ТВ.

## Настройки и диагностика

Настройки хранятся в `%LOCALAPPDATA%\ControllerHelper\settings.json`, предыдущая корректная версия — в `.bak`. Ключи сопряжения и токены защищаются Windows DPAPI для текущего пользователя. Перенос файла настроек на другой ПК не заменяет настройку дисплеев и новое сопряжение.

В `logs` находятся `launcher.log`, `errors.jsonl` и их ротированные версии `.1`. JSONL содержит не только ошибки, но и этапы операций, длительности и диагностические сведения. Метка завершения этапа или `visible=true` у окна не является доказательством появления изображения на экране.

Логи, пользовательские настройки и приватные ключи не включаются в Git. Перед публичной отправкой диагностических файлов проверяйте их содержимое. Материалы совместимости в `ThirdParty/Hisense` не являются персональными токенами сопряжения; их происхождение и ограничения публикации описаны в [NOTICE.txt](ThirdParty/Hisense/NOTICE.txt).
