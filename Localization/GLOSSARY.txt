ControllerHelper English / Russian terminology and review
Reviewed 2026-11-11. English (US) is the default; Russian remains available.

display = дисплей / экран
monitor = монитор (the PC desktop displays)
TV = телевизор / ТВ
display layout = раскладка дисплеев
resolution = разрешение
refresh rate = частота обновления
scaling = масштаб
audio output = аудиовыход
pair / pairing = сопрячь / сопряжение
standby = режим ожидания
wake = пробуждение / включение из режима ожидания
input = вход (the TV source, such as HDMI)
overlay = оверлей
D-pad = крестовина
stick = стик
shortcut = сочетание кнопок / ярлык (depending on context)
certificate fingerprint = отпечаток сертификата
unencrypted = без шифрования

Reviewed exceptions are product/protocol names (ControllerHelper, Flydigi,
Hisense, VIDAA, RemoteNOW, webOS, GameInput, HDMI, MQTT, TLS), abbreviations,
MAC/model example fragments (EE, QF), and the technical term "unencrypted".

Translation rules:
- Preserve resource keys and numbered format arguments, including :X and :d.
- Preserve leading/trailing spaces in message fragments and deliberate newlines.
- Do not translate device names, TV-provided input names, identifiers, commands,
  network payloads, log event IDs, or third-party names.
- User-visible errors belong in both catalogs; diagnostics event IDs stay stable.
- Application language is separate from numeric formatting used by protocols.
- A language change is saved with settings and takes effect after restarting.
- Windows/driver-provided messages may follow the operating system language.
