## 1. Подготовка и запуск

Нужны Windows 11 x64, работающий геймпад, доступный через Microsoft GameInput, и телевизор, подключённый к видеовыходу ПК. Установите Steam и хотя бы один раз откройте его: **в текущей версии действие «Играть на ТВ» требует Steam и всегда открывает Big Picture**. Отключения этого шага в настройках пока нет. Flydigi устанавливается по желанию.

1. Скачайте `ControllerHelper-…-win-x64.zip` из [последнего релиза](https://github.com/eleaf33/controllerhelper/releases/latest).
2. Распакуйте архив целиком в папку с правом записи, например `Документы\ControllerHelper`. Не запускайте приложение внутри ZIP.
3. Оставьте вместе `ControllerHelper.exe`, папки `lib`, `lang` и `build-manifest.json`. Запускать нужно только корневой EXE, но остальные файлы ему необходимы.
4. Запустите EXE обычным двойным щелчком, без прав администратора. Отдельная установка .NET не требуется.
5. Для русского интерфейса откройте **PC → Language / Язык → Русский**, нажмите **Save settings**, выберите **Exit** в меню значка приложения в трее и запустите его снова. По умолчанию используется английский.

При первоначальной настройке включите телевизор пультом и выберите HDMI, к которому подключён ПК. В **Параметры Windows → Система → Дисплей** воспользуйтесь определением экранов и убедитесь, что Windows умеет выводить картинку на ТВ. На время сохранения его раскладки можно включить расширение рабочего стола на телевизор.

Для первой локальной проверки оставьте пробуждение по сети выключенным, а **Input when switching to TV** — в положении **Do not switch input** («Не переключать вход»). Настраивайте сетевые функции после успешной проверки изображения.

**Ограничение публичного релиза:** скачиваемая сборка не содержит приватных протокольных ключей Hisense. В ней работают локальное переключение экранов/звука и Wake-on-LAN, но MQTT-сопряжение, выбор входа и выключение Hisense требуют собственной сборки с [материалами совместимости](../README.ru.md#локальные-материалы-для-hisense). Это ограничение не относится к LG.

## 2. Сохранение конфигурации ПК

1. В настройках дисплеев Windows расположите мониторы так, как они должны работать после возврата с ТВ. Там же выберите основной монитор, разрешения и частоты.
2. Откройте вкладку **PC** («ПК») в ControllerHelper. Если состав устройств изменился, нажмите **Refresh** («Обновить»).
3. В списке **Monitors** выберите все рабочие мониторы, которые нужно возвращать вместе. **Телевизор в этот список не включайте.** В момент сохранения каждый выбранный монитор должен быть активен в Windows.
4. В **PC audio output** выберите обычные колонки, наушники или звуковую карту. Этот выход также используется как резервный, если HDMI-звук ТВ недоступен.
5. Нажмите **Save PC layout** («Сохранить раскладку ПК»), затем **Save settings**. Проверьте сообщение об успешном сохранении внизу окна.

**Save PC layout** запоминает текущую конфигурацию выбранных мониторов Windows. **Save settings** сохраняет выбор устройств и параметры, но не заменяет сохранение раскладки. Если изменили набор выбранных мониторов, повторно сохраните раскладку, пока они активны.

## 3. Изображение и звук ТВ

### Изображение

1. Откройте **TV** («ТВ») и выберите телевизор в списке **TV**. Суффикс вроде `1234:1` — идентификатор устройства Windows, а не номер входа HDMI.
2. Пока выбранный ТВ активен в Windows, нажмите **Save TV layout** («Сохранить раскладку ТВ»). Кнопка запоминает рабочую конфигурацию; она сама не включает телевизор и не переключает на него изображение.
3. Нажмите **Refresh TV modes** для получения доступных режимов выбранного дисплея. Часть параметров можно прочитать, только когда ТВ активен в Windows.
4. Для первого теста оставьте **Resolution** и **TV-only scaling** в положении **Do not change** («Не изменять»). Позднее для конкретного режима выберите разрешение и **Refresh rate** из предложенных списков и сохраните настройки.
5. Нажмите **Save settings**.

Действие «Играть на ТВ» оставляет активным только выбранный телевизор. Карточка **Turn on monitors** в оверлее позволяет после этого добавить сохранённые мониторы ПК.

«Не изменять» означает отсутствие соответствующего дополнительного переопределения; сохранённый профиль дисплея всё равно участвует в переключении. Если сохранённый режим помечен недоступным, обновите список при активном ТВ и выберите режим, который Windows предлагает сейчас. Пользовательский системный масштаб может мешать отдельному масштабу ТВ: в таком случае оставьте **TV-only scaling** в положении «Не изменять» и настройте масштаб средствами Windows.

### Звук: HDMI и саундбар

1. Откройте **TV audio output**. Список устройств обновляется при каждом открытии.
2. Выберите HDMI-аудиовыход, связанный с телевизором или соответствующим выходом видеокарты. Имя приходит из Windows/драйвера и может содержать модель ТВ, NVIDIA, AMD или Intel.
3. Выход со статусом **not connected** («Не подключено») можно сохранить заранее. HDMI-звук может появиться только после активации изображения на ТВ.
4. Если устройство помечено **disabled in Windows** («Отключено в Windows»), включите его в настройках устройств воспроизведения Windows, если хотите им пользоваться. ControllerHelper не включает устройства, отключённые средствами Windows.
5. Сохраните настройки. После активации дисплея приложение ждёт выбранный выход ТВ до **10 секунд**. Если он не появился, пытается использовать выбранный выход ПК и показывает предупреждение. Ошибка аудио сама по себе не возвращает изображение на мониторы.

При подключении `ПК → HDMI → ТВ → HDMI ARC/eARC → саундбар` саундбар может не отображаться отдельным аудиоустройством ПК. Выбирайте HDMI-выход, который Windows предоставляет для этого подключения, а в телевизоре настройте вывод звука на саундбар. Сначала проверьте этот маршрут средствами Windows. Если HDMI-выхода нет, активируйте изображение ТВ, повторно откройте список и проверьте устройства воспроизведения Windows. Сохранённый выход со статусом «Устройство отсутствует» может относиться к прежнему подключению.

На время проверки изображения можно выбрать одно и то же рабочее аудиоустройство для ПК и ТВ.

## 4. Геймпад и аварийный возврат

1. Подключите геймпад и откройте **Controller** («Контроллер»).
2. Выберите нужное устройство в списке **Controller** и проверьте **Connection**. Если геймпада нет, проверьте его обнаружение в Windows и сообщение приложения о GameInput, если оно показано.
3. В **Overlay shortcut** задайте две разные кнопки одного геймпада. По умолчанию нужно удерживать **A + View примерно 0,5 секунды**. View — кнопка обзора/назад в обозначениях Xbox, не Menu.
4. Для неизвестного обозначения используйте **Capture first button** или **Capture second button**, затем нажмите нужную кнопку на контроллере.
5. Перед первым переключением можно включить **Emergency return to monitors** («Аварийный возврат на мониторы»). Предложенное сочетание — **LB + RB**, удержание **2 секунды**; сама функция по умолчанию выключена. Сочетание должно отличаться от вызова оверлея.
6. Нажмите **Save settings**.

Аварийный возврат восстанавливает сохранённую конфигурацию ПК и его звук, затем пытается закрыть Steam Big Picture. Он работает, пока ControllerHelper отвечает, а выбранный геймпад подключён. **Автоматического таймера, отменяющего переключение через несколько секунд, нет.** При первом тесте держите рядом клавиатуру и мышь.

## 5. Проверка переключения и работа двух экранов

Перед проверкой включите ТВ, выберите HDMI компьютера, сохраните обе раскладки и установите Steam.

1. На вкладке ТВ нажмите **Play on TV** («Играть на ТВ»). Изображение перейдёт на телевизор, изменится аудиовыход и откроется Steam Big Picture.
2. Удерживайте сочетание вызова оверлея. **Крестовина** выбирает карточку, **A** подтверждает, **B** закрывает оверлей.
3. Выберите **Turn on monitors** («Включить мониторы»). Сохранённые мониторы ПК станут доступны **одновременно с ТВ**. Телевизор остаётся активным; эта команда не меняет аудиовыход и не закрывает Big Picture.
4. Вторая карточка теперь называется **Turn off monitors** («Выключить мониторы»). Она убирает мониторы ПК из активной конфигурации, сохраняя работающий ТВ.
5. Для полного возврата выберите **Return to monitors**. Восстановятся профиль ПК и его звук, закроется Big Picture. Сетевое выключение ТВ зависит от настройки телевизора и показанного действия; это отдельная операция от переключателя мониторов.

| Карточка оверлея | Результат |
| --- | --- |
| Play on TV / Играть на ТВ | Профиль изображения/звука ТВ и запуск Big Picture; настроенные сетевые команды пробуждения и выбора входа. |
| Turn on monitors / Включить мониторы | Добавляет сохранённые мониторы к ТВ. ТВ, звук и Big Picture продолжают работать. |
| Turn off monitors / Выключить мониторы | Убирает эти мониторы из активной конфигурации; ТВ остаётся активным. |
| Return to monitors / Вернуться к мониторам | Восстанавливает профиль и звук ПК, закрывает Big Picture. Для сопряжённого Hisense также пытается выключить ТВ по сети. |
| Turn off TV and return to monitors / Выключить ТВ и вернуться к мониторам | Сначала возвращает дисплеи и звук ПК, затем пытается выключить настроенный ТВ. Подпись зависит от сетевого состояния. |
| Resume game / Close overlay | Закрывает оверлей, не переключая профили дисплеев. |
| Flydigi | Открывает отдельно установленный клиент Flydigi. |
| Close Telegram | Запрашивает закрытие Telegram; к переключению экранов эта команда не относится. |

Переключатель мониторов доступен, когда выбранный ТВ является активным дисплеем. В совместном режиме сохранённая группа мониторов размещается справа от активной области ТВ. Полный возврат восстанавливает сохранённую раскладку ПК. Поведение конкретной игры при изменении дисплеев зависит от самой игры.

## 6. Общие настройки сети

**Видеоподключение и сетевое управление — разные вещи.** HDMI передаёт изображение и звук ПК, а локальная сеть используется для пробуждения, выбора входа и выключения.

| Поле или кнопка | Что указать или сделать |
| --- | --- |
| Network control for the selected TV | Выберите **LG** или **Hisense**, затем раскройте соответствующий блок. Этот выбор определяет используемую интеграцию. |
| Local IPv4 address | Адрес ТВ в домашней сети, например `192.168.1.50`. Не адрес роутера и не внешний IP интернета. |
| MAC address | MAC активного сетевого подключения ТВ. У Ethernet и Wi-Fi разные адреса. |
| Check connection | Проверка локальной доступности и попытка определить MAC. Это не сопряжение и не проверка HDMI. |
| Wake … over the network | Отправка Wake-on-LAN при выборе «Играть на ТВ». ТВ должен поддерживать пробуждение и оставаться в режиме ожидания. |
| Input when switching to TV | Физический вход телевизора, куда подключён ПК, например HDMI 2. Не номер дисплея в Windows. |

Для автоматического заполнения MAC включите телевизор, введите его IP, оставьте поле MAC пустым и нажмите **Check connection**. Адрес заполнится только при успешном локальном определении; уже введённый MAC не перезаписывается. Если определить адрес не удалось, посмотрите его в сетевой информации ТВ или в роутере. Одного IP для Wake-on-LAN недостаточно: для сохранения включённого пробуждения нужен корректный MAC.

В этой реализации ПК и ТВ должны находиться в одной локальной IPv4-подсети. Гостевая Wi-Fi-сеть и изоляция клиентов могут мешать связи. Если роутер поменял IP телевизора, обновите его в приложении; резервирование DHCP позволяет закрепить адрес. Успешная проверка связи ещё не гарантирует пробуждение из ожидания. Отправка пакета также не доказывает включение ТВ, а Wake-on-LAN сам по себе не выбирает HDMI.

## 7. Настройка LG webOS

1. Включите LG вручную и разрешите поддерживаемое телевизором мобильное/сетевое управление. Названия параметров зависят от версии webOS; **TV On With Mobile** само по себе не гарантирует стандартный Wake-on-LAN.
2. В списке сетевого управления выберите **LG**, раскройте блок **LG**, введите локальный IP и нажмите **Check connection**. Определите или укажите MAC до включения **Wake LG over the network**.
3. Для обычной защищённой настройки оставьте **Allow legacy unencrypted mode** выключенным. Нажмите **Check TV certificate**, убедитесь, что показан адрес вашего ТВ, и подтвердите сертификат, если доверяете этому устройству. Приложение проверяет сроки действия сертификата.
4. Нажмите **Pair TV** и разрешите подключение на экране телевизора с помощью пульта. Дождитесь результата в приложении.
5. Пока ТВ включён, нажмите **Refresh TV inputs** внутри блока LG. Общая кнопка **Refresh** внизу обновляет устройства Windows, а не список входов телевизора.
6. В **Input when switching to TV** выберите HDMI компьютера и нажмите **Save settings**. Можно выбрать и вход с пометкой **no signal** («Нет сигнала»).
7. Проверьте сценарий, когда LG показывает Apple TV или другой источник: нажмите **Play on TV** и убедитесь, что телевизор выбирает вход ПК до переключения дисплеев Windows.
8. Когда переключение с уже включённым телевизором работает, отдельно проверьте пробуждение из ожидания.

Чтобы выбирать вход пультом, оставьте **Do not switch input**. Сетевой выбор входа можно использовать при уже включённом ТВ, не включая сетевое пробуждение. Если LG отклоняет смену HDMI, повторите сопряжение и подтвердите новый запрос разрешений. После изменения ТВ/IP/сертификата заново проверьте доверие и сопряжение. Режим без шифрования предназначен для старых совместимых моделей: он передаёт ключ открытым текстом и должен включаться осознанно в доверенной локальной сети.

## 8. Настройка Hisense VIDAA

Совместимость зависит от модели и прошивки. Интеграция разрабатывалась для **Hisense 55U7QF / VIDAA**; это не является заявлением о совместимости с Hisense на других операционных системах.

### Wake-on-LAN в публичной сборке

1. Включите поддерживаемую ТВ настройку **Wake on LAN**. Для Wi-Fi дополнительно нужна поддержка **Wake on Wireless Network**. Названия меню могут отличаться.
2. Выберите **Hisense**, раскройте его блок, введите локальный IP и нажмите **Check connection**, пока ТВ включён. Укажите MAC фактически используемого Ethernet- или Wi-Fi-подключения.
3. Включите **Wake Hisense over the network**, оставьте **Input when switching to TV** в положении **Do not switch input** и нажмите **Save settings**.
4. Переведите ТВ в ожидание пультом. Нажмите **Test wake without switching displays** и проверьте, включился ли телевизор. Эта проверка отправляет пакеты пробуждения без изменения экранов Windows.
5. Без MQTT-управления входом выбирайте HDMI компьютера вручную. Если версия VIDAA предлагает запуск с **Last Source** («Последний источник»), можно включить эту настройку и выбирать HDMI ПК перед переходом в ожидание. Это настройка самого телевизора, а не команда Wake-on-LAN.

### Сопряжение по PIN, выбор HDMI и выключение

Эти шаги требуют локальной сборки с [материалами совместимости Hisense](../README.ru.md#локальные-материалы-для-hisense). В публичном ZIP их нельзя разблокировать простым вводом PIN.

1. Включите телевизор вручную и разрешите поддерживаемое мобильное/дистанционное управление. Приложение на телефоне для сопряжения ControllerHelper не требуется.
2. Введите и сохраните правильные данные ТВ и сети. Нажмите **Pair Hisense**.
3. Проверьте и подтвердите запрос доверия сертификату, затем введите в ControllerHelper **четырёхзначный PIN, показанный на телевизоре**.
4. После успешного сопряжения при необходимости нажмите **Refresh TV inputs**, выберите HDMI ПК в **Input when switching to TV** и сохраните настройки.
5. Проверьте **Play on TV**. Если настроено пробуждение, отправляется Wake-on-LAN; выбранный вход переключается перед сменой дисплеев Windows.
6. Проверьте полный **Return to monitors**. После сопряжения приложение пытается выключить Hisense по сети после восстановления экранов и звука ПК. **Turn on monitors** сохраняет работающий ТВ.

При ошибке сопряжения проверьте точный текст ошибки, разрешение дистанционного управления на ТВ, дату и время ПК/ТВ и журналы. Не заменяйте протокольные ключи случайными файлами. Работа телефонного пульта сама по себе не доказывает поддержку той же прошивки/профиля протокола этой сборкой.

## 9. Flydigi

Установите Flydigi Space Station отдельно и проверьте, что обычный ярлык открывает рабочий интерфейс. ControllerHelper ищет EXE в стандартных местах установки; выбора произвольного пути в текущем интерфейсе нет.

Запускайте оба приложения обычным способом. Выберите **Flydigi** в оверлее и дайте клиенту время самостоятельно открыть окно. Левый стик двигает указатель, A выполняет щелчок или подтверждает клавиатурную навигацию, B отправляет Escape в клиент. Удержание X примерно секунду закрывает окно Flydigi штатной командой клиента. Скорость указателя регулируется в оверлее.

Если Windows сообщает об отказе в доступе, полностью завершите Flydigi через его значок в трее и запустите обычным способом. Если пустое окно возникает только внутри оверлея, сравните запуск через отдельный ярлык и приложите логи: видимый дескриптор окна ещё не доказывает отрисовку интерфейса.

## 10. Ежедневное использование, обновление и настройки

- Закрытие окна настроек оставляет ControllerHelper в системном трее. Из меню значка можно снова открыть настройки или полностью завершить приложение.
- Для сочетаний геймпада приложение должно работать. В текущем интерфейсе нет переключателя автозапуска; при необходимости создайте ярлык корневого EXE в папке автозагрузки Windows.
- Перед обновлением завершите старый экземпляр через трей. Полностью распакуйте новый релиз и запустите его корневой EXE. Если старый процесс ещё работает, новый запуск передаст запрос ему.
- Файлы программы переносимы, но настройки принадлежат пользователю Windows: `%LOCALAPPDATA%\ControllerHelper\settings.json`, резервная копия — `.bak`. Другая распакованная сборка на том же ПК и под тем же пользователем использует эти настройки.
- Данные сопряжения защищены для текущего пользователя Windows. На другом ПК заново выберите экраны/звук, сохраните раскладки, выберите контроллер и выполните сопряжение.
- Журналы автоматически записываются в `logs` рядом с корневым EXE, независимо от рабочей папки запуска. У пользователя должно быть право записи в эту папку.

## Решение проблем

| Что происходит | Что проверить |
| --- | --- |
| ТВ недоступен или отсутствует в списке | Включите его, выберите HDMI ПК, проверьте изображение в параметрах дисплеев Windows, затем обновите список приложения и выберите устройство. Сетевой доступ не означает доступность HDMI-дисплея. |
| Не сохраняется раскладка ПК/ТВ | Сохраняемые экраны должны быть активны в Windows. Телевизор не должен одновременно входить в список мониторов ПК. |
| Приложение требует Steam | Установите и запустите Steam для регистрации обработчика `steam://`. Сейчас он необходим для «Играть на ТВ». |
| ТВ продолжает показывать Apple TV | В нужном блоке производителя нажмите **Refresh TV inputs**, выберите порт ПК, сохраните настройки и проверьте разрешения сопряжения. Номер дисплея Windows не является номером HDMI. |
| Нет HDMI-звука | Активируйте изображение на ТВ, откройте аудиосписок заново и проверьте устройства воспроизведения Windows. Выбирайте актуальный выход, а не отсутствующее старое устройство. Звук саундбара может идти через аудиовыход ТВ. |
| Звук остался в колонках ПК | Выход ТВ мог не появиться за 10 секунд. Проверьте предупреждение и логи: звук ПК используется как резервный. |
| Недоступна частота или разрешение | Включите ТВ как дисплей Windows, обновите режимы и выберите доступный. Для первого теста используйте «Не изменять». |
| MAC не заполняется автоматически | Выполните проверку связи при включённом ТВ и пустом поле MAC. Если определить адрес не удалось, введите MAC активного интерфейса вручную. |
| Пакеты пробуждения отправлены, но ТВ не включился | Проверьте поддержку пробуждения в ожидании, MAC активного подключения, подсеть и изоляцию клиентов. Отправка пакетов не является подтверждением включения. |
| Hisense сообщает об отсутствии материалов | Публичный ZIP не содержит приватных ключей. Используйте локальное переключение/Wake-on-LAN или собственную сборку с нужными материалами; одного PIN недостаточно. |
| Сочетание не открывает оверлей | Проверьте выбранный контроллер и статус связи, сохраните две разные кнопки и удерживайте их около 0,5 секунды. Приложение должно работать. |
| После обновления ничего не изменилось | Завершите старый процесс через трей перед запуском нового EXE. Смена языка также требует сохранения и перезапуска. |

Для диагностики запишите действие и точное время попытки, версию приложения и Windows, видеокарту/драйвер, модель ТВ, схему подключения и результат ручного переключения изображения/звука через Windows. Приложите `logs/launcher.log` и `logs/errors.jsonl`; если запись уже ротирована, добавьте файлы `.1`. В `errors.jsonl` находятся и обычные диагностические события. Проверяйте журналы перед публичной отправкой; не публикуйте `settings.json`, данные сопряжения и приватные ключи.
